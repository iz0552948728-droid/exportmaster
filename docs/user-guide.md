# Модуль форматирования: как пользоваться

Программа берёт файл измерения (`.mtx`) и шаблон (`.md`), подставляет в шаблон
значения из файла и раскладывает результат по файлам — по одному на каждую
комбинацию, заданную в шаблоне.

Разработчику сюда не нужно: сборка, устройство и форматы описаны в `README.md`
и в соседних документах.

## Что передают пользователю

| Что | Зачем |
|---|---|
| `ExportMaster.Formatter.Cli.exe` | сама программа, один файл, ничего ставить не нужно |
| шаблон `.md` | под конкретный отчёт; за образец берут `samples/templates` |
| этот файл | инструкция |

Больше ничего: .NET устанавливать не требуется, программа собрана вместе
со средой исполнения.

## Запуск

```
ExportMaster.Formatter.Cli.exe /source C:\data\aaa.mtx /md C:\шаблоны\отчёт.md /target C:\out /id 1
```

| Ключ | Что задаёт | Обязателен |
|---|---|---|
| `/md <файл>` | шаблон | да |
| `/target <путь>` | каталог для результата, создаётся при необходимости | да |
| `/source <файл>` | файл измерения; без него выйдет пустой бланк с заглушками | нет |
| `/id <значение>` | номер задания, попадает первым полем в протокол | нет |
| `/overwrite no` | не перезаписывать уже существующие файлы | нет |

Пути с пробелами берут в кавычки. Ключи принимаются и в длинной форме: `--md`, `--source`.

## Что программа пишет

В стандартный вывод — по строке на каждый сформированный файл, пять полей
через табуляцию:

```
1  0  POL1=V;FREQ=2.490GHz  meas_V_2.490GHz.csv
1  0  POL1=H;FREQ=2.490GHz  meas_H_2.490GHz.csv
```

Это номер задания, код результата (`0` — успех, `1` — файл не сформирован),
ключ вырезки, имя файла и, если не успех, текст ошибки.

Код возврата процесса: `0` — сформированы все файлы, `1` — часть, `2` — задание
не выполнено (ошибка в аргументах или в шаблоне, файлов не будет ни одного).

Подробности об ошибках идут не в стандартный вывод, а в поток ошибок и в журнал:
папка `LOGS` рядом с программой, хранится 10 дней.

## Если что-то пошло не так

Сообщения написаны так, чтобы по ним было понятно, что исправлять. Самые частые:

**«Ось разбиения BEAM в файле данных отсутствует. В нём есть: POL1, FREQ, POS, DATA»** —
шаблон написан под другой файл. Исправить список в `{GROUPBY(...)}`.

**«Матрица имеет 4 измерений, поэтому GROUPBY должен содержать 2 осей, а содержит 1»** —
в `{GROUPBY(...)}` перечисляют все оси, кроме двух: оставшиеся две становятся
строками и колонками таблицы. Для файла с четырьмя осями в `GROUPBY` должно быть две.

**«Размер блока данных … не соответствует описанию»** — файл измерения записан
неправильно: в его метаданных объявлено меньше точек, чем лежит в самом файле.
Это не лечится со стороны отчёта, файл нужно переснять.

**«'XXX' не является полем заголовка»** — опечатка в имени внутри `{FIELD(...)}`.
Список имён — в ТЗ, п. 4.2.1.6.

При ошибке в шаблоне не создаётся ни одного файла: лучше ничего, чем правдоподобный
файл с молча пропущенным значением.

## Про шаблон

Шаблон — обычный текстовый файл. Всё, что между `[MDHEADER]` и `[/MDHEADER]`, —
настройки и в результат не попадает; ниже идёт тело, оно переносится как есть,
а поля в фигурных скобках заменяются значениями.

```
[MDHEADER]
{FILENAME("meas_", {GROUPVALUE("POL1")}, "_", {GROUPVALUE("FREQ")}, ".csv")}
{GROUPBY("POL1", "FREQ")}
{ENCODING("UTF-8-BOM")}
[/MDHEADER]
Вид измерения: {FIELD("MeasurementType")}
Антенна: {FIELD("AuxType")}; {FIELD("AuxIdentifier")}

{TABLE("POS", "DATA", "AMP", "0.000", ";")}
```

Четыре вещи, которые нужны почти всегда:

- `{FILENAME(...)}` — из чего складывается имя выходного файла, вместе с расширением;
- `{GROUPBY(...)}` — по каким осям бить на файлы; оставшиеся две оси идут в таблицу;
- `{FIELD("имя")}` — значение из заголовка файла измерения;
- `{TABLE(колонки, строки, величина, формат, разделитель)}` — сама таблица.

Две настройки, о которых спрашивают чаще всего:

- `{ENCODING("UTF-8-BOM")}` — чтобы Excel открыл кириллицу по двойному щелчку.
  Без этого он покажет мусор. Если файл читает не человек, а программа заказчика,
  BOM убирают: `{ENCODING("UTF-8")}`;
- `{DECIMAL(",")}` — запятая вместо точки в дробных числах, если так настроен Excel.
  Учтите: запятая попадёт и в имена файлов, где есть частота, — `meas_V_2,490GHz.csv`.

Полное описание языка шаблона — в `template-language.md`.
