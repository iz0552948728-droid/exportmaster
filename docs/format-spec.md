# Форматы файлов данных

Побайтное описание, по которому пишется разбор. Составлено по ТЗ ред. 1.0 от 29.07.2026
с учётом решений, согласованных в переписке.

> **Статус: раскладка подтверждена на образце.**
> Описание сверено с файлом `samples/data/aaa.mtx` от автора формата и с объявлениями
> структур, по которым он записан. Расхождения с ТЗ ред. 1.0 перечислены в конце
> и подлежат внесению в новую редакцию.
>
> Формат вектора (сигнатура 2) образцом пока не подтверждён.

## Общая структура файла данных

| Смещение | Размер | Поле |
|---|---|---|
| 0 | 4 | Сигнатура: `1` — многомерная матрица, `2` — вектор |
| 4 | 4 | Размер метаданных |
| 8 | *переменный* | Метаданные, состав определяется типом файла |
| … | *до конца файла* | Блок данных |

**Размер метаданных отсчитывается от начала файла**, включая сигнатуру и само поле.
Иначе говоря, это смещение, с которого начинается блок данных. В образце оно равно 101,
и данные действительно идут со 101-го байта.

**Порядок байт.** Шапка файла — сигнатура и размер блока метаданных — всегда little endian,
независимо от содержимого метаданных. Это необходимо: поле, задающее порядок байт, лежит
*внутри* метаданных и до их чтения недоступно.

Для всего остального — и для метаданных, и для блока данных — порядок байт задаёт поле
«формат» (см. ниже). У вектора такого поля нет, его числа читаются как little endian.

**Строки** во всех файлах данных — UTF-8.

## Сигнатура 1 — многомерная матрица

### Метаданные

| № | Размер | Поле |
|---|---|---|
| 1 | 1 | Вид блока данных: `0` — комплексные числа, `1` — вещественные |
| 2 | 1 | Формат: `1` — big endian, `2` — little endian |
| 3 | 4 | Количество описателей структуры, N |
| 4 | *переменный* | N описателей структуры подряд |

Описатель структуры:

| № | Размер | Поле |
|---|---|---|
| 4.1 | 1 | Тип значения — перечисление `Dimensions`, значения 1…8 |
| 4.2 | 2 | Количество **хранимых** значений — не число точек по оси |
| 4.3 | 1 | Способ задания списка: `0` — диапазон, `1` — список |
| 4.4 | 1 | Тип данных списка: `0` — стандартный список, `1` — строки, `2` — числа |
| 4.5 | *переменный* | Значения, состав зависит от 4.3 и 4.4 |

Варианты поля 4.5:

| 4.3 / 4.4 | Содержимое |
|---|---|
| стандартный список | ничего |
| список, строки | массив строк, разделённых нулями; число элементов равно 4.2 |
| список, числа | массив `double`; число элементов равно 4.2 |
| диапазон, числа | три `double`: начальное значение, конечное, шаг |

**Число точек по оси** совпадает с полем 4.2 только когда ось задана списком.
Для диапазона в поле 4.2 стоит `3` — число хранимых значений, то есть начало, конец и шаг, —
а точек получается `(конец − начало) / шаг + 1`. В образце у оси `POS` записано `3`,
а точек по ней 53.

**Последний описатель** всегда имеет тип `DATA` (позиция данных) или `FREQ` (частота).

### Типы значений — перечисление `Dimensions`

| Значение | Имя | Смысл |
|---|---|---|
| 1 | `FREQ` | частота |
| 2 | `POL1` | поляризация зонда |
| 3 | `CHANNEL` | канал |
| 4 | `BEAM` | луч |
| 5 | `DATA` | позиция по оси сбора данных |
| 6 | `POS` | позиция движения |
| 7 | `SLIDER` | позиция слайдера |
| 8 | `POL2` | поляризация приёмника |

Значение перечисления совпадает с байтом в файле. Эти же имена используются в списке
отбора данных в шаблоне и в ключе результирующего файла.

### Блок данных

Подряд лежащие одномерные массивы чисел.

- **Вещественные** — `double`.
- **Комплексные** — пара `double` (Re, Im) подряд.

Порядок следования массивов задаётся описателями структуры «начиная от последнего вверх»:
последний описатель — это ось *внутри* одномерного массива, предпоследний меняется быстрее
всех остальных при переходе между массивами.

## Сигнатура 2 — вектор

### Метаданные

| № | Размер | Поле |
|---|---|---|
| 1 | 2 | Количество элементов вектора, N |
| 2 | *переменный* | N описателей элементов подряд |

Описатель элемента:

| № | Размер | Поле |
|---|---|---|
| 2.1 | 4 | Размер блока данных элемента, байт (L) |
| 2.2 | 1 | Тип данных: `0` — double, `1` — int, `2` — строка, `3` — дата-время, `4` — bool |
| 2.3 | 1 | Тип структуры: `0` — одиночное значение, `1` — массив, `2` — диапазон |
| 2.4 | 20 | Наименование элемента, добито нулями до 20 байт; при длине ровно 20 завершающий ноль не требуется |

Разрядность типов данных:

| Тип | Представление |
|---|---|
| `double` | 8 байт |
| `int` | 4 байта |
| `bool` | 1 байт, значения 0 и 1 |
| строка | UTF-8, завершается нулём; ноль входит в длину |
| дата-время | **не определено** — до решения тип считается нереализованным и даёт явную ошибку |

### Блок данных

N произвольных байтовых последовательностей в порядке следования описателей,
каждая своей длины L.

- **Массив чисел** — количество элементов вычисляется как L / размер типа.
- **Массив строк** — строки с завершающим нулём подряд.
- **Диапазон** — три значения: начальное, конечное, шаг.
- Типы «строка» и «bool» не могут иметь структуру «диапазон».

## Отличия от ред. 1.0 ТЗ

Требуют внесения в новую редакцию документа.

| Что | Было в ред. 1.0 | Как в образце |
|---|---|---|
| Сигнатура | 2 байта | 4 байта |
| Размер метаданных | 2 байта, от начала метаданных | 4 байта, **от начала файла** |
| Счётчик описателей структуры матрицы | отсутствует | 4 байта перед описателями |
| Количество значений оси | подразумевалось число точек | число **хранимых** значений; для диапазона это 3 |
| Тип структуры данных вектора | `0` одиночное, `2` массив, `3` диапазон | `0` одиночное, `1` массив, `2` диапазон |
| Количество элементов вектора | 1 байт | 2 байта |
| Размер блока данных элемента (L) | 2 байта | 4 байта |
| Порядок байт шапки файла | не определён | всегда little endian |
| Разрядность чисел | не определена | `double` 8 байт, `int` 4 байта, комплексное — пара `double` |
| Кодировка строк | не определена | UTF-8 |
| Имя первой поляризации в примерах | `P1` | `POL1` |

Открыто: представление даты-времени (тип 3 вектора).

## Что подтверждено образцом, а что нет

Разбор `samples/data/aaa.mtx` сходится точно: метаданные заканчиваются ровно на объявленном
смещении, а размер блока данных совпадает с произведением длин осей на 16 байт (комплексное
число — пара `double`). Это подтверждает разрядность полей, порядок их следования, вычисление
длины оси по диапазону и вид значений.

**Порядок следования данных образцом не подтверждён.** Файл заполнен числами без внутренней
структуры: средний скачок между соседними точками отличается от скачка между случайными
парами всего на 18 %. Ошибка в раскладке осей не уронит разбор, а выдаст правдоподобные,
но неверные числа — единственный способ её поймать заранее — файл с узнаваемым содержимым,
например где значение выводится из индексов точки.
