# Export Master

МАСТЕР ЭКСПОРТА РЕЗУЛЬТАТОВ ИЗМЕРЕНИЙ — модуль форматирования.

Сливает markdown-шаблон с результатами измерений из двоичных файлов и сохраняет
результат в формате, принятом у заказчика. Применяется как в автоматизированных
сценариях (режим командной строки), так и для ручного экспорта.

## Сборка

```bash
dotnet build
dotnet test
```

Требуется .NET 8 SDK.

## Запуск

```bash
ExportMaster.Formatter.Cli /source DATA:matrix.bin /source MEAS:vector.bin \
                           /md report.md /target ./out /id 42
```

вместо значений. Чтение файлов данных ожидает новой редакции ТЗ.
